> 由于Kubernetes 1.24 以后使用containerd管理镜像 所以配置信息也和以前不一样
> 主要在于对containerd配置文件的设置 

### Harbor安装
[安装教程](/2023/07/02/harbor) 

### 修改containerd配置文件

#### 添加私有仓库host
```bash
cat>/etc/containerd/certs.d/192.168.89.133/hosts.toml << EOF
server ="http://192.168.89.133"
[host."http://192.168.89.133"]
capabilities = ["pull", "resolve", "push"]
skip_verify = true
EOF
```

#### 修改[plugins."io.containerd.grpc.v1.cri".registry.configs]
```bash
vi /etc/containerd/config.toml
```
```yaml
# 将mirrors移到config_path之前，并在下面添加
      [plugins."io.containerd.grpc.v1.cri".registry.mirrors]
# 配置私有mirrors
        [plugins."io.containerd.grpc.v1.cri".registry.mirrors."192.168.89.133"]
          endpoint = ["http://192.168.89.133"]
          
      config_path = "/etc/containerd/certs.d"
      
      [plugins."io.containerd.grpc.v1.cri".registry.configs]
# 跳过Https验证
        [plugins."io.containerd.grpc.v1.cri".registry.configs."192.168.89.133".tls]
          insecure_skip_verify = true
# 配置登录信息
        [plugins."io.containerd.grpc.v1.cri".registry.configs."192.168.89.133".auth]
          username = "admin"
          password = "Harbor12345"
```
#### 重启containerd
```bash
systemctl restart containerd
```
