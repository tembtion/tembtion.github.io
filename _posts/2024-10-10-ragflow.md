> 通过修改web程序实现通过地址登陆


### 修改web逻辑

复制[index.tsx][1]到 ragflow\web\src\pages\login\index.tsx
```javascript
  useEffect(() => {
    form.validateFields(['nickname']);
    init()
  }, [form]);
  // 相关业务代码
  const init = useCallback(async () => {
      const searchParams = new URLSearchParams(window.location.search);
      const authorizationParams = searchParams.get('authorization');
  
      if (authorizationParams) {
          localStorage.setItem('Authorization', authorizationParams);
  
          navigate('/knowledge');
      }
  }, []);
```
![alt](/assets/images/posts/2024-10-10-ragflow/6fc7853f-4027-4e38-bea8-fb26c0565187.png)

### 创建Dockerfile

复制 [DockerfileWeb][2]  到 ragflow\DockerfileWeb
```bash
FROM infiniflow/ragflow:v0.17.2-slim AS builder

WORKDIR /ragflow

COPY web web
COPY docs docs

RUN --mount=type=cache,id=ragflow_npm,target=/root/.npm,sharing=locked \
    cd web && npm install && npm run build

FROM infiniflow/ragflow:v0.17.2-slim AS production

WORKDIR /ragflow

COPY --from=builder /ragflow/web/dist /ragflow/web/dist
```

### 构建镜像
```bash
# docker build  -f DockerfileWeb -t infiniflow/ragflow:1.1 .
```
![alt](/assets/images/posts/2024-10-10-ragflow/1742896492429.jpg)

### 修改环境变量
```bash
# cd docker
# vi .env

修改
RAGFLOW_IMAGE=infiniflow/ragflow:v0.17.2-slim
为
RAGFLOW_IMAGE=infiniflow/ragflow:1.1
```

### 启动服务
```bash
# docker compose -f docker-compose.yml up -d
```
