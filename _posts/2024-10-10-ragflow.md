> 通过修改web程序实现通过地址登陆


## 修改web逻辑

复制[index.tsx][1]到 ragflow\web\src\pages\login\index.tsx

## 创建Dockerfile

复制 [DockerfileWeb][2]  到 ragflow\DockerfileWeb

## 构建镜像
docker build  -f DockerfileWeb -t infiniflow/ragflow:1.1 .

![alt](/assets/images/posts/2024-10-10-ragflow/1742896492429.jpg)

## 修改环境变量
```bash
# cd docker
# vi .env

修改
RAGFLOW_IMAGE=infiniflow/ragflow:v0.17.2-slim
为
RAGFLOW_IMAGE=infiniflow/ragflow:1.1
```

## 启动服务
docker compose -f docker-compose.yml up -d

## 访问服务
http://192.168.186.134/login?email=qq@qq.com&password=123456
