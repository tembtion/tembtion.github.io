> 将虚拟机磁盘容量从40G扩充到50G

#### 虚拟机VMware扩容大小设置

![alt](/assets/images/posts/2023-11-22-vmdisk/1732339184477.jpg)

#### 查看服务器磁盘信息
```bash
df -h
```
![alt](/assets/images/posts/2023-11-22-vmdisk/1732339337510.jpg)

#### 查看磁盘分区
```bash
fdisk -l
```
![alt](/assets/images/posts/2023-11-22-vmdisk/1732339426776.jpg)

#### 对新加的磁盘进行分区操作
```bash
fdisk /dev/nvme0n1
```
![alt](/assets/images/posts/2023-11-22-vmdisk/1732339637379.jpg)

#### 对新加的磁盘格式化
```bash
mkfs.ext4 /dev/nvme0n1p4
```
![alt](/assets/images/posts/2023-11-22-vmdisk/1732340374917.jpg)

#### 将物理硬盘分区初始化为物理卷
```bash
pvcreate /dev/nvme0n1p4
```
#### 显示物理卷详细
```bash
pvdisplay
```
![alt](/assets/images/posts/2023-11-22-vmdisk/1732341748354.jpg)

#### 获取卷组名称（VG Name）
```bash
vgdisplay
```
![alt](/assets/images/posts/2023-11-22-vmdisk/1732341018603.jpg)

#### 将物理卷/dev/nvme0n1p4加入卷组cs
```bash
vgextend cs /dev/nvme0n1p4
```
![alt](/assets/images/posts/2023-11-22-vmdisk/1732341857034.jpg)
#### 逻辑卷扩容
```bash
lvextend -L +9.9G /dev/mapper/cs-root
```

#### 扩展根分区
```bash
xfs_growfs /dev/mapper/cs-root
```

#### 查看扩容结果
```bash
df -h
```
![alt](/assets/images/posts/2023-11-22-vmdisk/1732341292751.jpg)
